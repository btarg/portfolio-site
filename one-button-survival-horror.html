Project Overview

This Resident Evil-inspired survival horror puzzle game was designed for a deliberately constrained brief: one 2D movement axis and one interaction button. It uses fixed camera angles and tank-style movement, with progression built around locked areas, key items, documents, and environmental clues.

Input and Interactions

I built an Unreal Engine style "player controller" singleton to centralise input handling. It measures button presses to distinguish a quick tap from a hold and gives the player a radial progress indicator while holding the button.

A tap uses the equipped item, such as firing a weapon. Holding the button opens the inventory or, when the player is near an interactive object, performs that object's contextual action. The same input model also supports navigating interface elements without adding extra buttons.

I also built a world interactable system inspired by Unity's Canvas UI navigation. World objects can define their neighbours, which I used to build keypads and combination locks.

Scope and Prioritisation

I completed inventory and weapon systems, but left them out of the final focus so I could spend more time on the puzzles. They were functional, but the project taught me to prioritise the systems that best support the core experience.
